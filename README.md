# Resumaker

A clean and simple resume maker for making a professional resume for technical roles.

## Features

- Live A4 preview that scales to fit any screen, with print-ready output
- Multiple resumes saved in your browser (localStorage): switch, rename, create and delete them from the resume menu
- Export a resume as JSON to back it up or share it, and import a `.json` file to load one
- Responsive layout with an Edit / Preview switch on small screens
